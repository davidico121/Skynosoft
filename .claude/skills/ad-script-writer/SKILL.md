# Ad Script Writer

Turns one chosen angle into a short-form script the team can shoot
themselves, either straight UGC-style or a more entertaining/concept-driven
piece. Every claim, stat, or quote in the script must trace back to the
research doc — this step writes words, it does not invent facts.

## Hard rules

1. **No invented claims.** No fabricated stats, review quotes, results, or
   "customers say" lines. If the script needs a claim the research doc
   doesn't support, flag it and ask, don't write it anyway.
2. **Cite your sources inline (in brackets) in the working draft** — e.g.
   `[review quote, Trustpilot]` or `[gap: no reviews on PDP]` — so anyone
   checking the script can see where each line came from. Strip brackets
   only from the final clean copy, keep a sourced version too.
3. **Format follows the angle, not a fixed template.** Default structure is
   hook → agitate/setup → product as solution → proof → CTA, timed for a
   15–30s short-form video. But if the angle is an entertaining/concept
   piece rather than straight UGC, the beats can bend (a concept doesn't
   need a literal "testimonial" beat) — the point is the hook still lands
   in the first 3 seconds and the CTA still closes it.
4. **Write for a real person to say on camera.** Natural spoken language,
   contractions, short sentences. Not ad-copy prose read aloud.

## Step 1: Confirm inputs

You need: the research doc (facts, review quotes, gap list) and the chosen
angle (from `ad-angle-generator` or given directly). If either is missing
or thin, say so before writing — don't script around a gap by making
something up.

## Step 2: Pick the format

Ask only if genuinely ambiguous, otherwise default:
- **UGC-style testimonial/problem-solve**: 15–30s, talent speaking straight
  to camera, natural pacing.
- **Entertaining/concept-driven**: still short-form, but the hook is a
  scenario/bit/joke rather than a direct testimonial. Still needs a clear
  product moment and CTA, just delivered with more creative license on
  structure.

## Step 3: Write the script

Beats (bend as needed per Step 1, rule 3):

1. **Hook (0–3s)** — must stop the scroll. Pull from a real pain point
   (review/comment language from the doc) or a strong concept opener.
2. **Agitate / setup (3–8s)** — the problem, in the audience's own words
   where possible (comments/reviews are gold here, cite them).
3. **Product as solution (8–18s)** — what it actually does, using only
   claims the brand's own site makes.
4. **Proof (18–25s)** — a real review quote, verbatim, cited.
5. **CTA (25–30s)** — clear, specific action (not generic "shop now" unless
   that's genuinely the brand's offer).

Write the full spoken line for each beat, plus a one-line note on what's
happening visually (full visual detail is `storyboard-builder`'s job, this
is just enough to write it with the picture in mind).

## Step 4: Output

Write the script into the lead's doc (or a linked companion doc) titled
`<Brand> — Script: <Angle Name>`. Include:
1. The sourced draft (with inline citation brackets)
2. The clean, shoot-ready version (brackets stripped)
3. A one-line note on format (UGC vs. concept) and estimated runtime

Handoff line: "Ready for `storyboard-builder`."
